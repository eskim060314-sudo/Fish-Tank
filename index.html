ABOUT FISH TANK

“Fish Tank is a shared virtual aquarium where anyone can create a fish and release it into the water. Every fish has its own name, personality, and story. Over time, the aquarium grows as more people contribute their fish.”

“Created as an Interactive Media Arts project exploring time, shared spaces, and data storage.”

📦

1. JSON Data

Every fish is represented as a pure JavaScript Object converted to JSON with its unique ID, custom colors, size, silly occupation, and ISO timestamp.

💾

2. localStorage

Enables instant local persistence using JSON.stringify() and JSON.parse() so your aquarium is preserved right in your browser offline.

🔥

3. Firebase Firestore

A cloud database with real-time listeners (onSnapshot) allowing fish created across different computers to swim together in the same tank.

⚙️

Database Status: Local Demo Mode

Running locally with browser storage. To connect your cloud Firestore database, paste your credentials into firebase-config.js!
